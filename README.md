# Demo result data

Generated from the uploaded `Machhu2_new.p02.hdf`.

- `metrics.json`: dashboard KPIs.
- `flood_extent.geojson`: dissolved inundation footprint for S1 at peak modeled breach flow.
- `depth_points.geojson`: sampled depth points for web visualization.
- `breach_timeseries.csv`: HEC-RAS breach flow/velocity time series.
- `dam.geojson`: Machhu-II dam point used for the map.

All numerical values are demo-only.
